## Sumber eksternal
- Paper: Fernández-Fontelo A., Cabaña A., Puig P., Moriña D. (2016). *Under-reported data analysis with INAR-hidden Markov chains*. Statistics in Medicine 35(26):4875–4890. DOI: 10.1002/sim.7026.
- Kode suplemen: `analysis/original/sim7026-sup-0001-examples.R`.
- Data HPV: Generalitat de Catalunya (weekly cases, 2008–2015) via file yang disediakan.
- Data Botulism: Public Health Agency of Canada, notifiable disease charts (rate per 100k), diunduh 2026-10-28/29.
- Data Mesothelioma: UK Health and Safety Executive, MESO01–03 (1968–2024), diunduh 2026-10-28.
- Populasi: World Bank `SP.POP.TOTL` (Kanada, Inggris), diakses 2026-11-01.
